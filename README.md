# ASCII Video Player 🎬

A simple Python script that plays any video file as ASCII art directly in your terminal, with the playback speed synchronized to the original video's FPS.

## Features

-   Plays video as text characters.
-   Matches original video Frame Rate (FPS).
-   Clears the terminal screen for a smooth animation effect.
